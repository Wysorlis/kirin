# KIRIN - A 2D Incompressible Euler Solver for Fun

KIRIN is a small 2D incompressible Euler solver written in Rust.

This project is developed purely for learning purposes:
- learning Rust,
- understanding numerical methods,
- and exploring the numerical solution of fluid dynamics equations.

The goal is to build the solver progressively, from a simple 2D grid to an interactive real-time fluid sandbox.
